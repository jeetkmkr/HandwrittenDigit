# ✍️ Handwritten Digit Recognition

A deep learning model that recognizes handwritten digits (0–9) with **99.9% accuracy** on the MNIST benchmark dataset using Convolutional Neural Networks.

![Python](https://img.shields.io/badge/Python-3.10-blue?logo=python) ![TensorFlow](https://img.shields.io/badge/TensorFlow-2.x-orange?logo=tensorflow) ![Keras](https://img.shields.io/badge/Keras-red?logo=keras) ![Accuracy](https://img.shields.io/badge/Accuracy-99.9%25-brightgreen)

---

## 📌 Overview

This project implements a CNN-based image classification pipeline trained on the MNIST dataset (70,000 grayscale images). It demonstrates the full ML workflow — from data preprocessing and augmentation to model training, evaluation, and inference.

---

## 📊 Results

| Metric | Score |
|--------|-------|
| Training Accuracy | 99.9% |
| Validation Accuracy | 99.4% |
| Dataset Size | 70,000 images |
